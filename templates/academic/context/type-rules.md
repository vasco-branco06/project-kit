# Type rules: academic

- Record in the overview: deliverable format, citation style ({{CITATION_STYLE}}), page limit ({{PAGE_LIMIT}}) and the teacher guide ({{TEACHER_GUIDE}}).
- Keep a source log in `source-log.md`; every value in the deliverable cites its source.
- Start deliverables at the content: no introduction about the task and no meta text.
- Before cutting pages, list each cut with the pages it saves and wait for approval.
- Final review: tables of contents, lists of tables, citations and references against the style.
