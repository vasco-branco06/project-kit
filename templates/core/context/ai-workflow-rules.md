# AI workflow rules

1. Stage one: inspect, ask and plan. Show the plan: objective, phases, how it is checked, risks.
2. Stage two: execute only what the owner approved.
3. Stage three: review against the done checks before saying a task is done; say what was tested and what was not.
4. Subagents never decide for the coordinator and never write outside the folder named in their brief.
5. Ask before anything destructive, external or hard to reverse.
