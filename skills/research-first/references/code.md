# Questions for code

- Language and library choice: the current version of each candidate, checked in its official documentation, and whether the stdlib already covers it.
- Style and structure: the language's official style guide or the large-company guide the community follows.
- Security: the relevant OWASP guidance or vendor advisory for the feature (auth, input, files, network).
- Testing approach recommended by the framework's own documentation.
- Dependency vulnerabilities and supply-chain risk (published advisories, maintainer activity) and licence compatibility between the chosen libraries.
- Existing libraries or repositories that solve the same problem: licence, last commit, maintenance, why reuse or not.
