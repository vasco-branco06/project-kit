# Questions for an app

- Platform: web, desktop or mobile; native, cross-platform or web wrapper. Read each platform's official guidelines (Apple HIG, Material, Microsoft design docs).
- Data and auth: where data lives, who can read it, which official auth flow applies (the provider's own documentation).
- Architecture pattern recommended by the framework vendor; avoid inventing one.
- Store, signing and distribution rules from the platform owner.
- Privacy and data protection duties, and accessibility requirements of the platform.
- Existing open-source apps of the same kind: licence, last commit, structure worth borrowing.
