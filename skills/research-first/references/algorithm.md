# Questions for an algorithm

- Is there a known solution: standard library, textbook, paper or RFC? Cite the original source, not a tutorial.
- Complexity in time and memory for the expected input size, and the worst case.
- Edge cases and failure modes named in the source.
- Reference implementations on GitHub: licence, test suite, last commit, known bugs in open issues.
- Numeric precision limits, and the source of any benchmark or dataset used. Never roll your own cryptography: use a vetted library.
- How to verify: published test vectors or a property to check against a simple correct version.
